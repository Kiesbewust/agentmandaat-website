# agentmandaat-website

Website agentmandaat.nl — statische site, deploy via Vercel.

Plain HTML, geen framework en geen build. **noindex until launch.**

## Structuur

- `index.html` — landingspagina
- `privacy.html` — privacytoelichting
- `llms.txt` — samenvatting voor AI-agents
- `robots.txt` — `Disallow: /` (nog niet indexeren)
- `sitemap.xml`
- `vercel.json` — `X-Robots-Tag: noindex, nofollow`
- `favicon.svg`
